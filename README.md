# 🍎🥦 Fresh Find

**Fresh Find** is a responsive frontend website for browsing and ordering fresh fruits and vegetables. It was built by **Team Digital Titans** for the **TechWiz Global** event at Aptech.

> ⚠️ This repository contains the **frontend only**. There is no backend or database integration.


---

## 📖 About the Project

Fresh Find aims to make buying fresh produce simple and enjoyable. Users can explore a wide range of fruits and vegetables through a clean, modern, and easy-to-use interface.

## ✨ Features

- Clean and responsive user interface
- Browse fruits and vegetables by category
- Product cards with images, names, and prices
- Mobile, tablet, and desktop friendly layout
- Easy navigation across all pages
